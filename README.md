# CUDA GPU 并行编程完全指南

一本系统性的 CUDA 编程中文电子书，涵盖从 GPU 硬件基础到高级并行优化技术的完整知识体系。

## 项目简介

本书是基于 NVIDIA 官方课程整理的 CUDA 编程完整教程，共 52 章，配套 79 张插图，适合从零开始学习 CUDA GPU 并行编程的开发者。

## 技术栈

- **排版系统**：LaTeX + XeLaTeX + ctex 中文支持
- **编译工具**：latexmk
- **代码示例**：CUDA C/C++

## 编译方法

```bash
# 完整编译（含目录生成）
latexmk -xelatex main.tex

# 或使用 Make
make

# 清理编译产物
latexmk -C
```

## 项目结构

```
cuda_ebook/
├── main.tex           # 主文件，包含文档设置和章节引用
├── ch1.tex ~ ch52.tex # 各章节内容
├── resources/         # 插图资源（79 张 PNG 图片）
├── Makefile           # 构建脚本
└── wrap_text.py       # 文本格式化脚本
```
