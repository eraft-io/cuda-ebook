\section{NVIDIA全系性能分析工具（Nsight Systems/Compute/nvprof）}


欢迎大家。今天我们将深入探讨 NVIDIA 为分析和剖析 CUDA应用程序提供的基本工具。在我深入介绍这七个工具之前，需
要注意的是 \texttt{nvprof}分析工具在许多教程中被广泛涵盖，但现已被弃用。我建议不要使用它，这就是它不会包
含在我的课程中的原因。

\subsection{CUDA-MEMCHECK与Visual Profiler}

如图所示，我这里有七个由 NVIDIA 提供的用于分析 CUDA应用程序的工具。无论如何，让我们从本文章中的工具开始，这
些工具由 NVIDIA 提供，例如 CUDA-MEMCHECK工具。该工具有助于识别和诊断 CUDA 应用程序中的内存错
误，包括越界和未对齐的内存访问错误，类似于可用于调试 CUDA程序的 cuda-gdb 工具。CUDA-MEMCHECK
工具对于确保 CUDA应用程序的正确性至关重要，而这反过来又会影响其性能。

我们在这个文章中的第二个工具是 NVIDIA Visual Profiler，简称 NVVP，以及针对CUDA、OpenCL、Direct3D 和 OpenGL 应用程序的硬件计数器。NVIDIA VisualProfiler 是一个跨平台

的性能分析工具，为开发者提供详细的时序信息。从其名称中的“Visual”一词我们可以知道其主要特点。该工具提供应用程序时
间线和达到的占用率的图形化视图。这有助于识别GPU 内核和内存传输中的瓶颈。

这里我想告诉你，我不会解释所有这些工具，我将只专注于 Nsight 套件中三个最重要的工具：NsightCompute、
Nsight Systems 和 NsightGraphics。这里的这张图解释了这三个工具之间的关系。如图所示，该图从
Nsight Systems开始，它相对于其他两个工具是外层的，这表明该工具更适合将应用程序作为一个整体来检查，而不是专
注于单个内核。这个工具即Nsight Systems被推荐给开发者，用于对其应用程序性能进行全系统范围的分析。当你考虑到
一个应用程序可能包含多个内核，而不仅仅是一个时，这种区别就变得明显了。该工具可以可视化CPU 到 GPU 的交互使用情况
，以及 CUDA Runtime API的性能，还能分析多节点工作负载。这就是为什么我们可以说 Nsight Systems是一个服务器端分析工具，而不是客户端分析工具。这个工具就是我在之前的文章中分析向量加法应用程序时演示过的同一个工具。


然后为了对应用程序或工作负载中的每个内核进行更细致的检查，Nsight Compute是首选工具。它提供了大量针对每个内
核的详细见解和度量指标，包括全局内存、缓存、流多处理器。甚至深入到流多处理器内的每个独立单元的度量指标，可用的度量指标超
过10万个。

Nsight Graphics提供有关图形帧和渲染性能的详细度量指标，专为图形应用程序分析和剖析的需求而定制。最后，当涉
及到以图形为中心的应用程序时，NsightGraphics 是该领域的专业工具。

在结束这个文章之前，我想留给你一个重要的提示。本课程中我们的分析重点将完全集中在 Nsight Compute工具的使用
上，可能还会涉及 Nsight Systems。
