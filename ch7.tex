\subsection{Fermi架构}

现在开始逐一讲解各架构，首先从 Fermi 架构讲起。Fermi 架构由 NVIDIA 于 2010 年推出，是 GPU 设计与技术的一次重大飞跃。

基于 Fermi 的 GPU 采用 40 纳米工艺制造。该架构的代表性芯片是 GF100，它被用于生产多款 GPU，既面向 HPC 市场，也面向
消费级市场。例如，Tesla X2070 是基于该芯片的 HPC GPU，而 GeForce GTX 480 则专为普通消费者和游戏玩家设计。如果你比

较这些性能指标，可能会疑惑：为什么面向普通用户的 GTX 480 在吞吐量和频率上似乎优于 Tesla X2070？具体来看，GTX 480 
的吞吐量为 1.3 TFLOPS、时钟频率为 700 MHz，而 X2070 仅为 1.2 TFLOPS 和 651 MHz。

要理解这一点，必须认识到评估 GPU 性能并非一目了然——GPU 的整体表现受多种因素影响，而非仅取决于这两个指标。仅凭 
TFLOPS 或时钟频率这样的单一数据，不足以全面衡量 GPU 的整体能力。此外，某一指标看似有利，在另一背景下可能恰恰相反。
例如，更高的时钟频率虽然能加速任务，但也可能导致功耗增加，这对某些系统来说并不理想。

另外需要说明的是，GTX 480 在单精度 TFLOPS 上看似优于 X2070，但这仅针对单精度运算，不代表 GPU 中所有核心的整体性能。
通过一个例子来说明：打开 TechPowerUp 网站对比这两款 GPU 时，你会注意到 X2070 的双精度性能约为 582.8 GFLOPS，远高
于 GTX 480 的 168.1 GFLOPS——几乎相差四倍。这类高双精度任务的典型代表就是科学仿真。然而在纹理和像素填充率等依赖单精
度运算的指标上，GTX 480 则优于 X2070，这也符合它面向游戏和日常应用的定位。

\subsection{Kepler架构}

接下来是 Kepler 架构。在 Fermi 发布两年后，NVIDIA 推出了 Kepler。从时间线可以看出，NVIDIA 大致每一到两年就会发布一款新
架构。Kepler 采用 28 纳米工艺制造，相比 Fermi 的 40 纳米实现了显著提升。

NVIDIA 的 GK210 芯片因应用于 Tesla K80 GPU 而闻名——这是一款 HPC GPU 加速卡。值得注意的是，Tesla K80 在一块板卡
上集成了两颗 GK210 芯片，而非一颗。凭借双芯片设计，K80 实现了约 8.2 TFLOPS 的吞吐量，相比 Fermi 架构提升了约六倍。
但需要注意的是，该数值是两颗芯片的总和，即每颗 GK210 芯片大约提供 4.1 TFLOPS。除 K80 之外，基于该芯片的其他知名 GPU
并不多，大多数面向消费市场的 Kepler GPU 均基于不同芯片。

关于 Kepler，还需提一下它的升级版本。有时 NVIDIA 会发布同一架构的增强版。例如，Kepler 最初于 2012 年推出，但在 2013 
至 2015 年间出现了迭代版本。类似的迭代也发生在 Maxwell 架构上。当你在 TechPowerUp 网站上查看 GK210 芯片时，会发现其
发布日期为 2014 年，与表格中的 2012 年不同——因为表格中的日期指的是该架构的最初版本。

\subsection{Maxwell架构}

Maxwell 架构由 NVIDIA 于 2014 年推出，是 GPU 领域的一项重大进步，同样采用 28 纳米工艺制造。该架构的旗舰芯片之一是 
GM200，被用于 Tesla M60 GPU（面向 HPC 设计）。对于游戏玩家而言，GeForce GTX 980 Ti 是另一款基于 Maxwell 架构的 
GPU。在吞吐量方面，M60 达到 9.7 TFLOPS，而 GTX 980 Ti 为 6.1 TFLOPS。在时钟频率方面，M60 运行于 557 MHz，而 
GTX 980 Ti 达到 1000 MHz。M60 的时钟频率较低，这直接与能耗相关——HPC GPU 更注重能效而非极限频率。

\subsection{Pascal架构}

从 Pascal 架构开始，HPC GPU 卡采用了"字母 + 100"的命名模式。在 Pascal 架构中，GPU 名称为 P100（P 代表 Pascal），这
一趋势延续到 Volta（V100）、Ampere（A100）和 Hopper（H100）。这种命名也体现在 GPU 芯片上：Pascal 有 GP100，随后的
Volta、Ampere 和 Hopper 分别有 GV100、GA100 和 GH100。Pascal 架构于 2016 年推出，采用 16 纳米和 14 纳米两种工艺
制造。你可能会疑惑，为何同一架构会使用两种工艺？原因在于当时不同制造商的技术水平不同——部分厂商已掌握更先进的 14 纳米
工艺，而其他厂商仍使用 16 纳米。尽管存在工艺差异，各公司仍能基于相同的 Pascal 架构生产 GPU，仅在纳米尺寸上有所不同。

关于 Pascal 架构此处不做过多展开，后续章节将结合白皮书和数据手册详细讲解剩余架构。仅从性能提升就足以说明一切：对比 
Fermi 的 1.2 TFLOPS 和 Hopper 的 378 TFLOPS，其间的飞跃一目了然（中间省略的 51 TFLOPS 将在 Hopper 架构章节中深入
解释）。
