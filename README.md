# CUDA GPU 并行编程完全指南

一本系统性的 CUDA 编程中文电子书，共 53 章、172 张插图，覆盖从 GPU 硬件基础、CUDA 环境搭建，到向量归约、矩阵乘法优化与张量核心编程的完整知识体系。

## 内容特色

- **体系完整**：从"GPU 与 CPU 的区别"讲起，逐步深入到张量核心与 cuBLAS 库编程，前后章节层层递进
- **理论结合实测**：每个优化技术均配以 Nsight Compute 实测数据，展示真实性能提升
- **深入底层**：解析 L1/L2 缓存机制、SASS 汇编、存储体冲突、竞态条件等容易忽视的底层细节
- **交互式演示**：配套 HTML 演示页面，直观感受 CPU 与 GPU 的算力差距

## 精华样章

### 第 1 章：GPU vs CPU

全书开篇。通过对比两者的缓存层级与 ALU 数量，直观回答"GPU 为什么擅长并行计算"：CPU 仅有少量 ALU，而 GPU 拥有成百上千个计算核心，奠定了全书理解 GPU 并行架构的基石。

### 第 16 章：第一个 CUDA 项目——核函数与执行配置

CUDA 的 Hello World。通过"打印块和线程 ID"这一最小项目，讲透 `__global__` 修饰符、核函数调用语法与执行配置参数（`<<<grid, block>>>`），是 CUDA 入门的必读章节。

### 第 24 章：GPU 占用率与延迟隐藏

性能优化的核心概念。区分"理论占用率"与"实际占用率"，讲解如何通过计算 Warp 数与 SM 上限评估资源利用率，并阐述占用率如何通过 Warp 切换隐藏内存访问延迟。

### 第 35 章：共享内存技术详解

介绍 GPU 内存层次结构中延迟仅 20--25 周期的共享内存，系统讲解存储体（Bank）组织方式与存储体冲突（Bank Conflict）的成因与规避方法，是理解后续所有共享内存优化的基础。

### 第 37--40 章：向量归约实战系列

全书最完整的优化案例链：

- **第 37 章**：仅用全局内存实现向量归约基准版本，建立树状归约模型
- **第 38 章**：完整代码解析，结合 Nsight Compute 剖析执行时间与缓存行为
- **第 39 章**：第一项优化——移除取模过滤器，执行时间从 283 微秒降至 176 微秒，并从汇编层面解释原因
- **第 40 章**：引入并行编程的核心挑战——竞态条件，通过 Release/Debug 编译差异现象，深入剖析线程读写冲突

### 第 44 章：屋顶线模型分析

性能分析方法论。介绍 Roofline 模型，教你科学判定应用属于计算受限（Compute-Bound）还是内存受限（Memory-Bound），为性能优化指明正确方向。

### 第 46 章：使用共享内存优化矩阵乘法

分块（Tiling）技术的完整实践。从"矩阵 A 的一行需要从全局内存读取多少次"这一关键问题出发，讲解瓦片划分、K 维循环累加与双重同步，实测获得约 30%--40% 的性能提升，并剖析瓦片大小的选取约束。

### 第 49 章：张量核心技术详解

现代 GPU 的计算心脏。讲解 Tensor Core 自 Volta 架构以来的演进史，说明其为何是深度学习加速的关键硬件，并与 AMD 的矩阵核心进行对比。
