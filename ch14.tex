\section{在 Linux 系统上安装 CUDA 工具包}

大家好，在今天的文章中，我将讲解如何在 Linux 系统上安装 CUDA工具包。假设你正在使用本节之前某个文章中所介绍的
WSL工具。你需要做的是打开开始菜单，搜索“命令提示符”，然后点击打开。如你所见，这就是我们的命令提示符窗口。你只需输
入 \texttt{wsl} 即可在当前 Windows 操作系统上启动你的 Linux 子系统。

\subsection{检查nvcc}

现在我们需要检查 \texttt{nvcc} 编译器是否已安装在我们的 Ubuntu系统中。这将需要几秒钟时间。如你现在
所见，我们正在启动 Ubuntu 系统。但终端提示 \texttt{command not found}，说
明 \texttt{nvcc} 尚未安装。

\subsection{安装CUDA工具包}

我们需要安装 CUDA 工具包才能使用 \texttt{nvcc} 编译器。如你在此处所见，我正在打开 CUDA工具包下
载页面，然后选择操作系统、架构以及发行版本。我们有多种发行版可选，我将选择 Ubuntu。如果你使用的是 WSL工具，也
可以选择 WSL-Ubuntu。接着你会看到三个安装选项：其中两个会先下载标为 Local的本地安装包，中间那个则是通过
网络直接安装（Network）。不过，我将采用最简单、最不容易出错的方式，如你在此处所见。

让我们再检查一次 \texttt{nvcc} 版本，虽然提示命令未找到，但第二行给出了安装建议：
\begin{verbatim}
sudo apt install nvidia-cuda-toolkit
\end{verbatim}

我将复制这条指令并在终端中输入，然后输入密码。此时系统会询问你是否要继续，输入 Y 确认即可。安装过程大约需要30--4
0 分钟，请耐心等待。一旦安装了 CUDA 工具包，你就拥有了 \texttt{nvcc}编译器以及本节第一个文章中介绍
的所有其他功能。安装完成后，如你在此处所见，我们只需再次检查 \texttt{nvcc}编译器，因为它已包含在 CUDA
工具包中。

现在让我们检查版本。如你所见，CUDA 编译器已成功安装，版本为 11.5。第一行显示 \texttt{nvcc:NVIDIA (R) Cuda compiler driver}，这表示 CUDA工具包已就绪。 这对入门来
说已经足够了。

另外我要提醒一点：如果你按照官网的步骤操作，可能会遇到一些依赖问题或错误。因此我建议你一开始先使用上述\texttt{apt} 指令，它很简单而且不易出问题。等你熟悉之后，需要更新 CUDA 工具包时，就可以前往 CUDA官网，选择适
合你系统的最新版本进行安装。
