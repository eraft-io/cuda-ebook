\section{如何阅读 GPU 技术白皮书}

白皮书本质上是 GPU 架构的深入技术规格说明书，在比较不同 GPU 时具有不可估量的价值，因为它们提供了对每个架构规格和能力
的详细洞察。回到下面的表格，你会注意到针对每个架构，我们都列出了一个基于该架构的芯片示例。

\subsection{搜索白皮书}

要获取任何架构的白皮书，只需一次简单的互联网搜索：打开浏览器，输入芯片名称后加上"白皮书"，芯片名称可从上述表格中获取。
例如，搜索表格中的芯片名称 GF100 加上白皮书，回车后即可看到一系列搜索结果。

\begin{figure}
    \centering
    \includegraphics[width=0.75\linewidth]{resources/cuda-045.png}
    \caption{搜索白皮书}
    \label{fig:placeholder}
\end{figure}


寻找指向官方白皮书的 PDF 链接——该链接应指向一份包含完整技术规格的 PDF 文档。同样地，如果你在研究 Ampere 架构，搜索
GA100 白皮书即可。注意不要被文章或摘要所误导，你真正需要的是原始的全篇白皮书。

英伟达有一个很有帮助的做法：在其白皮书中将新架构与旧架构进行比较。例如，A100（Ampere）的白皮书会与其前任 Volta（V100
）和 Pascal（P100）进行性能对比。

你可能会在 A100 和 H100 的白皮书中看到展示不同单元和指标的同一张表格。所有白皮书中的这种一致性意味着一
旦你理解了如何浏览并解读一份英伟达白皮书，也就具备了理解其他白皮书的能力。

\subsection{白皮书的结构}

英伟达的白皮书通常遵循标准化的结构，按顺序包含以下四个要点：第一，新技术与特性的介绍；第二，流式多处理器（SM）的内部
组件和结构；第三，性能基准测试与比较；第四，技术规格。

第一点——新特性的介绍：每份白皮书都以突出展示新技术和增强功能的部分开头，内容涵盖从人工智能专用核心（如张量核心）到改进
的图形着色技术，乃至软件或硬件的任何增强。

第二点——SM 架构分析：所有白皮书都会深入探讨新型 SM 的内部结构，正如你在不同白皮书的对比图中所见，每个架构都会与其前
任进行比较。第四点——技术规格：每份白皮书都包含详细规格，如核心数量、内存大小、内存带宽、内存技术、功耗要求等，全面展示
GPU 的能力。

\subsection{SM内部结构}

我们将重点关注第二点——即 SM 的内部结构。英伟达的白皮书深入剖析了每个 GPU 的 SM 设计，其后通常是前文讨论过的通用对比
表。例如，查看 P100（Pascal 架构，GP100 芯片）的白皮书，你会看到一张展示整个 GPU 的图片，然后是 SM 的详细图表及其内
部组件，如 CUDA 核心和内存层级结构。转向 V100（Volta 架构）白皮书时会发现类似的布局，然而一个显著的增强是增加了张量核
心单元——Volta 架构中包含了张量核心，而 Pascal 架构中则没有。

接下来看 A100（Ampere 架构）的白皮书。同样，这份白皮书展示了整个 GPU，然后是 SM 内部结构的详细信息。对比表被移到了
另一个部分，但仍在白皮书中。Ampere 架构中 SM 的内部结构与 Volta 非常相似——比较两者图片即可发现，差异并不显著。

查看 H100（Hopper 架构）白皮书时，这种一致性依然存在：先展示整个 GPU，然后是 SM 内部结构的详细信息。Hopper 与前代

架构的主要区别在于每个 SM 中可用的核心数量。例如，可以数一下 Hopper 中有多少个 32 位浮点核心，再与 A100 比较，即可看出
差异。

总结而言，虽然每份白皮书都针对其特定的 GPU，但所有白皮书提供的结构和信息类型都遵循相似的模式。这种延续性和一致性不仅使
专业人员更容易跟上最新技术，而且有助于清晰地理解技术进步，以及每个新架构相较于其前任的定位。
